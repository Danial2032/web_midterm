# web_midterm

# Online web courses

Alibayev Danial, Aben Aibar, Aidynuly Makhambet

This is the web-site with online web courses. Web-site shows available courses and displays info about the instructors.

Features implemented:

The project uses 7 web pages with their own css. It is possible to use navigation on the top to select the web-page. Registration and table with CRUD. 

Technologies used: 

Project uses HTML and CSS files. It uses Bootstrap, Media queries and Flexbox. Bootstrap is used for simplyfying css structure by using bootstrap css. Media queries are used to make web-site readable in mobile phones, tablets and laptops. Flexbox is used to create boxes that use space effectively. Javascript and JQuery were used to implement interactive elements.
